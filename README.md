# PA WebSprint - Landing Page

Sitio web profesional y completamente optimizado para PA WebSprint: "Páginas web profesionales en tiempo récord, sin precios inflados."

## 🚀 Características

- **Next.js 14** con App Router para máximo rendimiento y SEO
- **React 18** con componentes funcionales y hooks
- **Tailwind CSS** para diseño moderno y responsive
- **Lucide React** para iconos modernos y escalables
- **TypeScript** para código seguro y mantenible
- **Optimización SEO** con metadata, schema.org
- **Core Web Vitals** optimizados (LCP, CLS, FID)
- **Mobile-First** responsive design
- **Transiciones suaves** y animaciones profesionales

## 📋 Secciones

1. **Navigation** - Navegación fija con menú móvil
2. **Hero** - Propuesta de valor principal con CTA
3. **Sprint Effect** - Beneficios clave (Velocidad, Rendimiento, Precio, Tecnología)
4. **Services** - Planes de precios (Startup, Professional, Enterprise)
5. **GEO SEO** - Posicionamiento local en Google
6. **About** - Información sobre Pablo Alberdi
7. **FAQ** - Preguntas frecuentes con acordeón
8. **Contact** - Formulario de contacto + WhatsApp
9. **Footer** - Links, redes sociales

## 📦 Instalación

```bash
cd webpersonal
npm install
npm run dev
```

## 🚢 Deploy

```bash
# Vercel (recomendado)
npm install -g vercel
vercel
```
